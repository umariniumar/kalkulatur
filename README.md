# Kalkulatur v1.3

MVP Kalkulator eFaktur untuk membantu menghitung transaksi dengan dua mode harga jual:
- Sudah termasuk PPN
- Belum termasuk PPN

Tambahan v1.3:
- Penjelasan istilah Harga Jual, Harga Barang, DPP, PPN, PPh23, dan Jumlah Bersih.
- Opsi menghitung/tidak menghitung PPh23 2% per perhitungan.
- Formula pada panel Rumus mengikuti formula workbook untuk mode yang tersedia di workbook.

Upload isi folder ini langsung ke root repository GitHub yang terhubung ke Vercel.
